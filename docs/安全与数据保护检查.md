# CRM 安全与数据保护检查

检查日期：2026 年 8 月 25 日

检查环境：本地 `test` profile，数据库 `crm_system_test`，应用端口 `3001`

适用范围：当前 CRM Web 应用、API、认证、上传下载、审计日志、自动化测试和发布包。

## 一、检查结果

本轮完成了依赖、认证、请求来源、上传文件、日志与审计脱敏、环境隔离和发布包内容检查。静态安全检查与真实 HTTP 安全流程均通过，Playwright 22 个按钮和恢复场景全部通过。

自动化安全检查只允许使用 `test` profile，并要求数据库名以 `_test` 结尾。检查过程未向 stable 或线上数据库写入测试数据。

## 二、已实施的保护

### 1. 认证与会话

- 认证密钥长度不足时拒绝启动，不使用弱默认密钥。
- stable 与 test 使用不同认证密钥、认证地址、数据库和上传目录。
- Cookie 使用 `HttpOnly` 和 `SameSite=Lax`；通过 HTTPS 或可信反向代理访问时启用 Secure Cookie。
- 用户被停用或会话过期后，API 返回明确的 401，登录成功可返回原页面。
- 日志不会记录完整 Cookie、Token、认证密钥或数据库连接串。

### 2. 请求来源与浏览器安全

- API 写请求检查 `Origin`、`Sec-Fetch-Site` 与配置的外部访问地址；跨站伪造写请求返回 403。
- 响应统一增加 Content Security Policy、`X-Frame-Options`、`X-Content-Type-Options`、Referrer Policy 和 Permissions Policy。
- 非法 JSON、内部异常和数据库错误不会把堆栈或内部路径返回给浏览器。
- 客户端提交的非法 `requestId` 会被替换，服务端生成的请求号同时写入响应头、错误响应和审计记录。

### 3. 文件上传与下载

- 上传同时校验文件大小、扩展名、浏览器 MIME、文件头签名和文件名。
- PDF、PNG、JPG、Word 等文件不能只靠修改扩展名绕过检查。
- 文件名中出现目录分隔符或路径跳转字符时拒绝上传。
- 下载和删除继续执行登录、权限和数据范围检查。
- 上传失败不写入文件元数据，也不在上传目录保留半成品。

### 4. 日志、审计与客户隐私

- 应用日志对 Authorization、Cookie、数据库连接串、Access Key 和 Secret Key 进行遮盖。
- 审计摘要对密码、令牌、密钥、电话、邮箱、地址等字段进行脱敏。
- 导入、转移、认领、订单、回款、设置和权限变更保留操作者、时间、`requestId` 及前后摘要。
- 本轮数据库检查未发现关键写操作缺少操作者、`requestId`，也未发现前后摘要同时缺失的记录。

### 5. 环境与发布包

- test 无法复用 stable 的数据库连接、认证密钥、认证地址或上传目录。
- 发布包采用明确白名单，不包含 `.env`、日志、测试脚本、Playwright 状态、截图、trace、上传文件或数据库备份。
- 发布包包含 `scripts\manage.py` 运行所需的 `scripts\cli`、`scripts\runtime` 和 `scripts\deploy`。
- 发布扫描会检查当前环境中的密钥和连接串是否意外进入白名单文件。

## 三、React 19 兼容处理

项目升级到 React 19 后，Ant Design v5 的静态 `message` 和 `Modal.confirm` 首次 E2E 检查无法渲染。API 和数据库写入实际成功，但页面没有成功提示或确认框。

现已在客户端 Provider 入口加载 `@ant-design/v5-patch-for-react-19`。同时，E2E 运行器改为每次先构建 test production 产物，避免源码更新后仍测试旧 `.next` bundle。重新构建后，客户新增、编辑、归档、删除、转移、公海认领、文件上传、离线提示和设置保存均通过。

## 四、已登记限制

- 项目规则固定使用 Next.js 15.4，本轮依赖审计仍登记 `next` 运行依赖风险。当前没有 critical 运行依赖风险，但不能表述为“所有公开风险已消除”。后续允许升级 Next.js 小版本时，应重新执行依赖审计、类型检查、生产构建和 22 项 E2E。
- Content Security Policy 当前为兼容 Ant Design CSS-in-JS 保留 `'unsafe-inline'` 样式。若后续改为 nonce，需要同时验证服务端样式注册、弹窗、图表和移动端布局。
- 本轮自动化检查针对本地 test 环境。线上反向代理 TLS 配置、云防火墙、数据库最小权限、备份介质权限和对象存储策略仍需在实际服务器执行只读核对。
