## 统一状态

- 加载：表格、卡片或表单使用 `loading`、`Spin`，不能显示旧数据并假装已刷新。
- 空数据：列表和提醒显示明确空状态，不显示成功提示代替数据。
- 失败：页面显示业务错误或请求号；写入失败不关闭表单、不清空允许保留的草稿。
- 无权限：菜单和按钮隐藏，直接访问页面或 API 返回 403；最终权限以 Route Handler 为准。
- 重复操作：提交按钮进入 loading，写请求使用 `requestKey`，服务端继续校验事务和状态。
- 危险操作：删除、停用、归档、禁用提醒和合同删除必须经过确认。

## 布局与可访问性

- 桌面侧栏固定，1024 像素以下切换抽屉导航；手机端隐藏账号姓名但保留账号入口。
- 1440、1280、1024、768 和 390 像素视口检查页面横向溢出、按钮可达、弹窗内容和表格滚动。
- 标题使用 22px 页面级字号；紧凑表格、弹窗和卡片不使用 hero 级文字。
- 键盘焦点使用可见轮廓；表单字段保留可读标签；图标按钮保留文字或 `aria-label`。
- `prefers-reduced-motion` 下关闭侧栏和顶栏位移动画。
